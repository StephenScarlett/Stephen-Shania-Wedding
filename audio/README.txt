This is a placeholder folder for background music.

TO ADD BACKGROUND MUSIC:
1. Place your audio file here (e.g., background.mp3)
2. The music player button in the bottom-right corner of the site will play this file.
3. If your file is named something other than "background.mp3",
   update the <source> tag in index.html near the bottom of the file.

Note: Browsers block autoplay — visitors must click the music button to start playback.
Supported formats: .mp3, .ogg, .wav
