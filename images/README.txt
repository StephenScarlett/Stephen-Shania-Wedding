This is a placeholder folder for gallery images.

TO ADD YOUR PHOTOS:
1. Place your image files here (e.g., photo1.jpg, photo2.jpg, etc.)
2. Open index.html
3. Find the gallery section
4. Replace the <div class="gallery-placeholder"> elements with:
   <img src="images/photo1.jpg" alt="Description" class="gallery-img">

Supported formats: .jpg, .jpeg, .png, .webp
Recommended size: 800-1200px wide for good quality without being too large.
